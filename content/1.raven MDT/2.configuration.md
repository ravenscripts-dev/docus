# Configuration

All Raven Scripts products come with a number of configuration options, below is a table of different configuration options and how they are used.

| Option Name       | Type    | Default Value | Description                     |
|-------------------|---------|---------------|---------------------------------|
| `exampleString`   | string  | "default"     | A placeholder string option.    |
| `exampleNumber`   | number  | 10            | A placeholder numeric option.   |
| `exampleBoolean`  | boolean | true          | A placeholder boolean option.   |
| `exampleArray`    | array   | []            | A placeholder array option.     |
| `exampleObject`   | object  | {}            | A placeholder object option.    |

### Example Configuration
```js
Config = {
    exampleString = "custom value",
    exampleNumber = 25,
    exampleBoolean = false,
    exampleArray = {"item1", "item2"},
    exampleObject = { key = "value" }
}
```
