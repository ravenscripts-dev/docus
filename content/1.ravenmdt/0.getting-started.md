# Dependencies

::alert{type="danger"}
Please Note: QBCore is not supported by Raven Scripts in any of our resources! Please use [QBox](https://github.com/Qbox-project).
::

### Framework
- **ESX** or **QBox**: Ensure your server uses one of these frameworks to provide essential base functionality.

### Database
- **ox_mysql**: A performant and reliable database wrapper for interacting with your MySQL database. Ensure it is properly installed and configured on your server.

### Libraries
- **ox_lib**: A versatile library that simplifies common script functionalities like progress bars, notifications, and menu interfaces. Install it via npm or your server's resource manager.

## Installation

1. **Install Dependencies**:
    - Install **ESX** or **QBox** based on your server framework preference.
    - Add **ox_mysql** to your server resources and configure your database connection.
    - Add **ox_lib** to your server resources by following the official installation guide.

2. **Configure Resources**:
    - Ensure that the required resources are started in the correct order in your `server.cfg` file.
      ```
      ensure ox_lib
      ensure ox_mysql
      ensure raven_mdt
      ```

3. **Test Functionality**:
    - After installation, restart your server and verify that the dependencies load without errors.
    - Check your server console for any dependency-related warnings or errors.
